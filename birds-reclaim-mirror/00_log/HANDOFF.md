## 2. 動かし方
- ふだん：`node birds-reclaim-mirror/server.js` → Chrome で `http://localhost:4182`。カメラを許可する。
- `index.html` を Chrome で直接開いても動くはず（部品は CDN から読む。通信が要る。ユーザーがどちらの開き方で確かめたかは未聴取）。
- 通信なし：`./get_vendor.sh` を1回 → `node server.js` で開く。`H` のパネルに「部品：ローカル（通信なし）」と出る。
- 見比べ用のキー：`↑↓` 鳥の大きさ　`←→` マスの大きさ　`−` `＝` 鳥の増え方　`[` `]` 払われて離れる距離　`;` `'` 払いが届く範囲。タッチでは右下の歯車。
- 開くと題の画面のまま、すぐカメラを始める（「カメラで始める」の画面は v0.7 でやめた）。重ねた画面はカメラを使えなかった時だけ。音は画面を一度さわるまで鳴らない。
- キー：`H` 設定　`F` 全画面　`A` / `B` 欠けた所　`N` 色　`G` 粒子　`M` 音　`R` 背景の撮り直し　`0` 鳥をやり直す　`D` 動きの検出を表示。
- 確かめ用の URL
  | URL | 何をするか |
  |---|---|
  | `?test` | カメラなし。合成の人影（70 秒でひと回り）。開発の確かめ用。画面からは選べない |
  | `?test&seg` | 同上＋切り出しも走らせて時間を測る |
  | `?img=画像のURL` | 静止画を入力にする（別オリジンから読める画像だけ） |
  | `?cdn` | `vendor/` があっても CDN から読む |
  | `?cpu` | 切り出しを CPU で動かす |
- コンソール：`__dbg.step(n, dt)` で時間を進める。`__stats` に状態。`__dbg.bench(n, dt, true)` で1コマの処理時間。アプリ内ブラウザは隠れていると描画が止まるので、これで確かめる。

## 3. コードの地図（`index.html` の中、上から）
| 節 | 内容 |

| 合成の人影 | `synth()`、`person()` |
| 鳥・編隊・群れ | `birdS()`、`slot()` / `shape()`、`stepBirds()`、`impact()`、`kill()` |

## 4.5 決まったこと（2026-11-11、ユーザー）
- 欠けた所は **B（草木）**。色は白黒＋総攻撃の一瞬の反転。
- 既定値：マス 12px（PC は 14px のまま）、増え方 4 倍、上限 220 羽、鳥の大きさ 2.4 倍、欠けが戻るまで 4 秒、払う感度 1.3、払いの範囲 0.7、離れる距離 1.3。スマホで試して決めた値。
- 作品の名前は **VÖGEL**（副題なし）。ただし画面には題字を出さない（v0.16、ユーザー：タイトルもいらない、テキストのみ）。無人の画面は問いの言葉だけ。名前はブラウザのタブとトップのリンクに残る。フォルダ名と URL は `birds-reclaim-mirror` のまま。
- 無人の時は題の画面。真っ黒ではなく、ほぼそのままの部屋の映像（幕 20%。v0.13 の 66% は暗すぎるとユーザー）の上に題字と言葉が乗る。文字のあたりだけ帯状に暗くし、文字に影を付けて読めるようにしている。人を検知して 9 秒かけてゆっくり薄れ、その途中（消え始めて約 1.6 秒）から鳥が来る（題と鳥の出現が重なってよい、とユーザー）。無人が 5 秒続くと、7 秒かけてゆっくり題に戻る。その間は静寂で、9〜22 秒に一度、遠い声だけが響く（`tick()` の `intro`、`draw()` の末尾、`audioTick` の `titleCry`）。題字と言葉は専用のキャンバス `#t`。
- 始まりの画面の説明は蛇足なので外した。下端の小さな1行（映像は送信も保存もしない）だけ、こちらの判断で残してある。
- リンチ的な世界観（夢と現実、日常とその裏の悪夢、低周波、甘くレトロな旋律と不穏なノイズ。キーワードであって全部入れる話ではない）：v0.4 で旋律つきの「夢の音」と「鏡が遅れる瞬間」（`lagT`）を試作。旋律は v0.6 で外した（ユーザーが不要と判断）。特定の作品の絵や曲は写さない。
- 題の画面の題字の下に、存在を問う1文（`QUOTES`：ライプニッツ、ウィトゲンシュタイン、ヘーゲル、ニーチェ）。無人に戻るたびに替わり、時折、字が乱れる（`drawQuote`、`glT`）。足す時は、没後 70 年以上の作者に限り、原典の本文で照らしてから。
- **音は鳥の声だけ**（ユーザー、v0.5 を聞いて）。旋律・羽音・つつく音はいらない。不穏さは、鳥が増えると声が少し変わることで出す（`shriek` の `u`）。あるとすれば聞こえるかどうかの低音（`ambInit`）。うるさくしない。
- 奥行き（v0.8、試作）：一部の鳥が手前から大きなぼけた影として飛び込み、払うと手前へ逃げる（`goFront` / `stepFront`、鳥の `z` と `fz`）。ユーザーの感想：意外といい、野暮でない、もっと大きくてもよい。v0.9 で、手前の鳥を 4〜7.5 倍に、人物の後ろを回る鳥（`goBehind`、`drawFar`。下のキャンバスに描く）と、後ろ姿の形（`birdR`）を足した。
- **途中に変な演出を入れない**（ユーザー、v0.10 を見て）：恣意的で、あざとい。ホラー映画ではない。背景のざらつきの波と乱れ、幕のちらつきは v0.11 で外した。鏡が遅れる瞬間は既定で切。画質は、いつも同じおだやかなフィルム調（わずかなぼかし、浮かせた黒、粒子）だけにする。鳥の輪郭はくっきりさせない（白い縁取りをやめた）。輪郭のやわらかさは 1.6（やわらかめがよい）、輪郭のしきい値は 0.8（ユーザーがスマホで決めた。v0.12 で既定に）。
- **映像の遅れ**（v0.17、ユーザーの案）：カメラの映像を数秒遅らせて出す（既定 5 秒、設定で 0〜10 秒）。立ってもすぐには自分が現れず、言葉を読んでいるうちに少し前の自分が入ってくる。認識・鳥・払いはすべて遅れた映像で行う。リアルタイムには払えない、過去の自分が払うのを眺めるだけ、でよい（ユーザーの判断）。スマホの実機で動くことはユーザーが確認（2026-11-11）。何秒がよいかは検証中。`useSource` / `ringPush`、`camOK` と `srcOK`。
- 現在と過去の混在（v0.18、試作。設定「現在と過去」。既定は「過去だけ」）：「いまを重ねる」（いまの自分が薄い影として二重に見える）と「行き来する」（遅れがゆっくり縮んで現在に追いつき、また開く）。ユーザーの感想待ち。5 秒の遅れそのものは「いい感じ。これでもいい」。
- カメラなしで見るモードは画面から外した（`?test` は開発の確かめ用に残す）。設定の歯車は残す。
