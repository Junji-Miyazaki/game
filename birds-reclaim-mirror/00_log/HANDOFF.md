## 2. 動かし方
- ふだん：`node birds-reclaim-mirror/server.js` → Chrome で `http://localhost:4182`。カメラを許可する。
- `index.html` を Chrome で直接開いても動くはず（部品は CDN から読む。通信が要る。ユーザーがどちらの開き方で確かめたかは未聴取）。
- 通信なし：`./get_vendor.sh` を1回 → `node server.js` で開く。`H` のパネルに「部品：ローカル（通信なし）」と出る。
- キー：`H` 設定　`F` 全画面　`A` / `B` 欠けた所　`N` 色　`G` 粒子　`M` 音　`R` 背景の撮り直し　`0` 鳥をやり直す　`T` 合成の人影　`D` 動きの検出を表示。
- 確かめ用の URL
  | URL | 何をするか |
  |---|---|
  | `?test` | カメラなし。合成の人影（70 秒でひと回り） |
  | `?test&seg` | 同上＋切り出しも走らせて時間を測る |
  | `?img=画像のURL` | 静止画を入力にする（別オリジンから読める画像だけ） |
  | `?cdn` | `vendor/` があっても CDN から読む |
  | `?cpu` | 切り出しを CPU で動かす |
- コンソール：`__dbg.step(n, dt)` で時間を進める。`__stats` に状態。`__dbg.bench(n, dt, true)` で1コマの処理時間。アプリ内ブラウザは隠れていると描画が止まるので、これで確かめる。

## 3. コードの地図（`index.html` の中、上から）
| 節 | 内容 |
|---|---|
| 設定 | `DEF`（既定値）、`UI`（パネルの行）。足す時はこの2か所と `applyCfg` |
| 画面とマス目 | `layout()`。マスごとの配列（`occ` 人物か、`hole` 欠けの残り秒、`hp` 強度、`lum` 明るさ） |
| 入力 | `setSrc()` で作業用キャンバスを作る。`MODE` は `cam` / `test` / `img` |
| 切り出し | `loadSeg()`、`readMask()` |
| 見る | `sense()`：切り出し → 動きの検出 → 背景の板 → マス目 → 体の速さ（`calm`） |
| 合成の人影 | `synth()`、`person()` |
| 鳥・編隊・群れ | `birdS()`、`slot()` / `shape()`、`stepBirds()`、`impact()`、`kill()` |
| 音 | 元ゲームから写したまま |
| 描く | `drawBlocks()`、`drawPlants()`、`filmGrain()`、`draw()`。下のキャンバス `#a`（映像とマス、CSS で白黒）と上の `#b`（草木・鳥・粒子。色が付く）。ネガは `#stage` に `invert(1)` |
| 進める | `tick()`、`loop()`、`stat()` |
| カメラ・UI・キー | `startCam()`、`buildUI()`、`keydown` |

- 行の途中に `//` の説明を書かない（後ろの処理が消える。LOG の「途中で直したこと」）。変えたら `node --check` で確かめる。
