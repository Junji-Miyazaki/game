# 音列と諸要素の定義 — 人に説明するための文章

SCORE FOR THE IMPOSSIBLE（v2.4「総音列の観測」）の音がどう決まっているかを、
展示の場や口頭で説明するためのテキスト。短い版から順に深くなる。

---

## 30秒で説明するなら

「この作品では、音はひとつも即興されていません。開始の瞬間に**サイコロが一度だけ振られ**、
音の高さ・長さ・強さ・立ち上がり・響きの色・リズムという6つの性質それぞれに
**順番のリスト（音列）**が決まります。あとはシステムがそのリストに厳密に従うだけです。
ただし、音を実際に鳴らすのは画面を往復する**観測線**で、観測線はすべてを捕らえられません。
聴こえている音楽は、**厳密な規則と、観測の失敗との、差分**です。」

---

## 1. 基本原理 — サイコロは一度だけ

この作品はランダムに音を鳴らしているのではない。**偶然が介入するのは「音列を作る瞬間」だけ**で、
それ以降のすべての音は決定論的に導かれる。シェーンベルクに始まりブーレーズやファーニホウに至る
「セリエリズム（音列主義）」の方法である。

音列（セリー）とは、**要素を一度ずつ使い切る順列**のこと。たとえば12個の音高を
「どれも繰り返さず、どれも欠かさず」並べた列。作品の開始時（と数十秒ごとの「サイコロ」イベント時）に、
各パラメータの列がシャッフルされて確定する。以後、音が必要になるたびに列から**順番に**値を取り出し、
使い切ったら先頭に戻る。好みや文脈で音を選ぶ余地は、システムのどこにもない。

## 2. 六つの音列 — トータル・セリエリズム

1950年代の総音列主義（トータル・セリエリズム）にならい、音高だけでなく
**音を構成するすべての性質**を音列で統べている。

| パラメータ | 音列の中身 | 音への現れ方 |
|---|---|---|
| **音高** | 0〜11の順列（12音列） | 後述の3段階で周波数に変換 |
| **リズム** | 分割比の順列 | 拍をいくつに割るか（3連・5連・7連…の入れ子） |
| **強度** | pppp〜ffff の8段階の順列 | 音量 |
| **アタック** | 2〜60ミリ秒の6値の順列 | 立ち上がりの鋭さ |
| **持続** | 0.25倍〜5倍の8値の順列 | 音の長さ（32分音符〜4秒の持続音） |
| **音色** | 倍音 1,2,3,4,5,7 の6値の順列 | 純粋なサイン波に薄く重なる倍音の色 |

## 3. 音高が決まる3つの段階

ひとつの音の高さは、3つの層を通って決まる。

**第1層 — 音列（順序）**: 12音列が「次はリストの何番目か」という**索引**を与える。
列はそのままの形（P）だけでなく、鏡像（I: 反行）、逆向き（R: 逆行）、鏡像の逆向き（RI）でも
読まれる。数学的には索引 x に対する変換 **x ↦ (±x + t) mod 12**（アフィン写像）で、
フレーズごとに変換の種類と移高 t が切り替わる。

**第2層 — モード（音の場）**: 索引は音を直接指定せず、**その時代のモード**に写される。
モードはメシアンの**「移調の限られた旋法」**から選ばれる——全音音階（モードI）、
八音音階（モードII）、モードIII、IV、VI、VII、そして半音階（＝12音すべて。音列技法の極）。
これらの旋法は対称構造を持つため移調の数が限られており（モードIは2種、IIは3種しかない）、
その数学的性質そのものが響きの個性になる。数十秒ごとの「サイコロ」でモードと移調が
振り直され、**時代（エポック）ごとに世界の響きの色が変わる**。
全音音階の時代は靄のように、八音音階の時代は張りつめて聴こえるはずである。

**第3層 — 微分音（滲み）**: 最後に、半音よりさらに細かい**八分音**（半音の1/4）の偏差が
加わる。生まれつきの偏差（微分音の音列）と、粒子どうしの**衝突で蓄積する傷**である。
モードの上に、ニュー・コンプレキシティ特有の肌理として微細な狂いが乗る。

式で書けば: **周波数 = 220 × 2^(s/48)**、
**s = 4·(モード[索引] + 移調) + 48·音域 + 微分音 + 傷**。

## 4. 音列行列（マトリクス）— 楽譜の楽譜

画面右上の12×12のドット行列は、十二音技法の伝統的な**音列マトリクス**である。
成分は **M[i][j] = (r_j − r_i) mod 12**（r は現在の音列）。この作り方から、

- 対角線はすべて 0 になり（表の背骨）、
- **行を左→右に読むと原型 P**（12行で12種の移高すべて）、**右→左で逆行 R**、
- **列を上→下に読むと反行 I**、**下→上で逆行反行 RI**

となり、12移高 × 4形態 = **48通りの読み方**が一枚に畳み込まれる。
シェーンベルク以来、作曲家が「音列の全変化形の地図」として使ってきた実務の道具である。
いわば、**ひとつの音列という遺伝子の、全変異体カタログ**。

画面上では: 点の大きさ＝成分の値、明るい**行**＝いまP/R形で読んでいる場所、
明るい**列**＝I/RI形で読んでいる場所、**赤い点**＝いままさに消費された音
（システムが表のどこを読んでいるかのカーソル）。数十秒ごとに表全体が組み変わるのは、
サイコロ＝音列の再シードの瞬間である。

なお本作（v2.4以降）では、この行列が出す値は音高そのものではなく**モードへの索引**であり、
その時代のメシアン旋法が索引を実際の音に写す。ひとことで言えば——
**行列＝順序の法則（どの順で読むか）、モード＝音の場（何が聴こえるか）**。
人に示すなら「これはこの作品の**楽譜の楽譜**です。鳴る音を直接書いたものではなく、
音を選ぶ順序の法則を全変化形込みで示した地図で、赤い点がいま読まれている場所です」。

## 5. リズム — 拍を有理数で割る

リズムは「何分音符」の羅列ではなく、**拍の入れ子分割**で作られる。
ひとつの拍を5つに割り、その1つをさらに7つに割る——という再帰で、
発音時刻は必ず**分数（有理数）**になる（例: 1拍の 8/35 の位置）。
どの分割比を使うかも音列（連符比の列）が決める。環境が騒がしいほど入れ子は深くなる。

## 6. 観測者 — 音楽が生まれる場所

ここまでの規則で「あるべき楽譜」は完全に決まっている。しかし音を実際に鳴らすのは、
画面を往復する**観測線**である。粒子（＝音符）と観測線が出会ったときに初めて音が確定するが、

- **観測から漏れる**ことがある（遠い粒子、若い粒子、疲れた観測者）→ 楽譜には**淡い休符**が書かれる
- **捕らえたのに記録に失敗する**ことがある → **赤い休符**が書かれる
- 記録できても、集中力に応じた**誤差**（タイミングの揺れ、音高の滑り）を伴う

観測者の集中力は微分方程式 **Ċ = ρ − δ(X, M)** に従って消耗と回復を繰り返す。
つまり、聴こえる音楽は「決定論的な楽譜」そのものではなく、
**楽譜と、不完全な観測との差分**である。画面下の大譜表には、鳴った音が正確な音高と長さで、
鳴らなかった音が休符として記譜されていく——沈黙も含めて、すべてが楽譜になる。

## 7. まとめの一文

**「偶然は最初の一投にだけ宿り、以後のすべては厳密である。
けれど、それを聴き取る者が不完全であるために、音楽になる。」**
