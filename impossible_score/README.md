# SCORE FOR THE IMPOSSIBLE — 不完全な演奏機械

ニュー・コンプレキシティ（超複雑系）をコンセプトにしたインタラクティブ・サウンド＆ビジュアルインスタレーション。単一HTML・依存ライブラリなし。PC / iPhone Safari 対応。

10のバージョンがある:

- **`index.html`（I. 不完全な演奏機械）** — 「黒い魔術書」風のリアルタイム生成楽譜（五線・連符ブラケット・微分音記号）
- **`v2.html`（II. 神はサイコロを振る）** — 量子測定メタファーのミニマル点描（時間駆動）。未来の音＝確率雲（重ね合わせ、揺らぎは誤差期待値に比例）が右から流れ、固定カーソル＝観測で1点に確定。脱落音＝観測されなかった空の環。浮上する数式・点描の音列行列・フルクサス風の一行指示・静寂なノイズ床。聴覚トリック3種を実装: ①レジスター音脈分凝（低/中/高の3声部を固定音域帯に閉じ込め対位法化）②定量反復セル（3〜6音を凍結し逐語反復、演奏エラーは毎回振り直し＝同じ不可能への再挑戦）③潜在パルス（可聴閾すれすれの拍。連符はこの基準への緊張として聴こえる）
- **`v2.1.html`（II.1 相対速度の観測）** — v2の時間駆動ベース。粒子は右→左に流れ、速度は奥行き z に比例（奥=0.6倍、手前=1.4倍、音量にも反映）。z はフレーズ単位なので反復セルは繰り返しごとに違う深度・違う速さ＝同じ素材の多重テンポになる。観測線は左→右→左…と等速で往復（22px/s、粒子より遅い）し、粒子と出会った瞬間に音の運命が確定——タイミングは相対速度から生じる（線が右向き=圧縮、左向き=伸長）。各粒子は速度ベクトルを持つ物理シミュレーションで動き、**同じ深度層（|Δz|<0.18）の粒子同士がブラウン運動的に弾性衝突**して向きを変える（衝突の閃輪、まれに Σp=const が浮上）。衝突後は「運命」（左向きの流れ＝観測へ向かう）と「意思」（セリー由来の固有軌道: 法則=(pc+q) mod 4、ω=有理分母、φ=拍内位置、A=強弱×奥行き）へゆっくり緩和して戻る——偶然（衝突）と必然（セリー）のせめぎ合い。衝突は質量つき弾性衝突（質量∝奥行き、軽い方が加速し重い方が減速、速度変化は緩和τ=8秒でしばらく残る）。発音タイミングは物理的な出会いから創発する。反復セルは構成粒子を細線で結ぶ星座として表示。観測のたびに**v1様式の楽譜の破片**（五線断片・符頭・微分音矢印・強弱記号、脱落=赤×、スリップ=赤矢線）がその場に結晶し、世界の流れに乗って15秒で溶ける——観測線が世界を記譜していく演出。時間の基準は音声クロック（rAF間引きでも音と絵がズレない）
- **`v2.2.html`（II.2 生の観測）** — 個体出生モデル＋衝突生殖＋寿命。無の空間に約4秒ごとに「同種」のファウンダーが誕生（7体まで）し、衝突時に確率 p·(1−N/K) で子が生まれる（成熟4秒・クールダウン3秒）。子は両親の形質（音高類・強弱・奥行き・運動法則）を混合継承し、25%で音列由来の突然変異——同種から始まり、相互作用の履歴だけが個性を作る。寿命はGompertz型ハザード（中央値約45秒、過密で増大）で、滅亡→再創世が循環する。音は観測線との出会いの瞬間のみ生成され、音の生成は出生確率を一時的に押し上げ、環境（マイク・カメラ）は環境収容力Kを動かす——繁栄と滅亡は設計されず力学から創発する。大きさ＝年齢（若い生は確率雲のように淡く小さく、老いた生は確かで大きく重く、音も大きい）。フェルマータ中は観測者が目を閉じ、生は記録されずに過ぎる。数理パネルにはロジスティック式 λ=λ₀N(1−N/K) とハザード h(a)=h₀e^(a/16) がライブ表示される
- **`v2.3.html`（II.3 記譜される生）** — v2.2の個体群モデル × 一方向の時間flow × 正確な記譜。粒子は右→左へ一方向に流れる（時間の不可逆性）。誕生は右端（ファウンダー）と衝突点（子）、左端到達＝時の彼方へ退場。観測の間引き: 交差しても捕捉確率（奥行き・成熟度・観測者の集中に依存）で漏れ、捕捉されても記録に失敗（赤環・記譜されない）しうる——「観測されない/鳴らない/鳴る」の3種。画面下部に**大譜表リボン**（ト音・ヘ音、音部記号付き）が常設され、**鳴った音だけ**が実音高（幹音＋♯＋微分音矢印▲▼、加線、スリップ込みの実際に鳴った高さ）と実長（4分〜32分の符尾）で正確に記譜され、右から入って左へ流れる。各音符の下に `220.0Hz` `120ms` の機械可読マイクロテキスト——**第二のデバイス（スマホ/Macのカメラ）がこの画面を撮影して譜面を読み取り再演する「カメラ演奏者」構想のためのパート譜**。記譜数学は±120ステップ全域でラウンドトリップ検証済み（譜面から実音が一意復元可能）。発音粒子から譜面へ因果線が走る
- **`v2.4.html`（II.4 総音列の観測）** — トータル・セリエリズム（B.ファーニホウへの立ち返り）。生成はv2.1のアルゴリズム（3声ストリーム×入れ子連符×反復セル×ブラウン衝突＋傷）に復帰し、粒子を増殖させる——観測線の間引きが「編集」として意味を持つ密度。セリーを全音響事象に適用: 音高（12音列＋48EDO）、リズム（連符比）、強度（8段階）、アタック（2〜60ms）、**持続（倍率セリー0.25×〜5×→32分音符から4秒の持続音まで）**、**音色（倍音セリー: サイン＋第2/3/4/5/7倍音を薄く混ぜる6段）**。記譜リボンは**真の時間軸**（位置＝観測時刻、同時音は自動的に縦に揃い和音として記譜）で全音価対応（白符頭の2分/全音符含む）。**休符を記譜**——観測から漏れた音は淡い休符、捕捉されたが記録に失敗した音は赤い休符として、あるべき長さの休符記号が書かれる（間引きの記譜）。観測から漏れた粒子は確率雲のまま流れ去る
- **`v2.5.html`（II.5 引力と反復）** — v2.4＋Phase A（音楽性の修正）。①重心音: 潜在パルスを時代の旋法の根音に音高化し、8〜16拍ごとに低域の持続ペダル（注視が深いほど確かに）——三和音なしの「ある種の調性」＝引力の中心。②アイソリズム・セル（タレア×コロル）: 反復セルは同じ時間スパンを反復ごとに違う連符数（3→5→4→7→6）で再分割し、音高列を回転させて割り当てる——外形は反復（ミニマル）、内部は再分割のズレが回転（超複雑）。③注視→協和: 静寂・静止が続くほど（τ=30秒の気候）選ばれる旋法が協和側（I,VI…）へ収束し、騒がしいと半音階まで崩壊。HUDに注視度A表示
- **`v2.6.html`（II.6 知識のグラフ）** — 医学研究の営みを写す版。設計書=DESIGN_v2.6.md。**データ→場／観測→質感の二軸分離**を貫く: 心臓病学の7概念（飽和脂肪・コレステロール・心疾患・喫煙・スタチン・塩分・糖＝各々固有の音色と音域帯のライトモチーフ、発音で上部の知識グラフのノードと凡例が点灯＝ラベル同期）の共起グラフが「何が鳴りうるか」（音程の協和度・重心音・微分音の傷・反復の執拗さ）を決め、観測エンジンが「どう鳴り損なうか」（漏れ・失敗・揺れ・入れ子連符の複雑性）を決める。複雑性は観測の質感でありエビデンスの記号ではない。エポック=10年（1950–2020をループ）、結合の強い概念ほど根音に協和し、係争・逆転は微分音のうなり、定説の覆り（飽和脂肪→心疾患の逆転劇）で音程が崩壊、撤回は赤い休符の連打。**必然性を主張せず**、データが手作業の模型であること・写像が作者の選択であることを常時開示（「地図は領土ではない」）。サイコロは排除されるが必然も騙らない
- **`v2.7.html`（SCORE FOR EVIDENCE — 三部作）** — v2.6の知識グラフ・エンジンを三部作の器に。プロジェクト名を SCORE FOR THE IMPOSSIBLE から **SCORE FOR EVIDENCE**（score=楽譜であり臨床スコアmRSでもある二重の意味／evidence=この作品が写す対象そのもの、その生成と崩壊）へ。曲名は英語。起動画面で3曲選択: **I. 飽和脂肪と心疾患**（確立→崩壊）/ **II. アルコールと循環器**（偽りの保護→「安全な量はない」の逆転）/ **III. 急性期再開通療法と脳卒中予後**（混沌→確立）。各曲7概念×5〜8相の手作業の関係グラフ（模型）。**音響強化**: 確立した主張ほど執拗に反復（reps 5〜8・間隔短縮）、低音域の持続音（全音符）＋純正5度・オクターヴの常設ドローンベッド（相交代で setTargetAtTime のスラー）で和声の底を作る、逆転相では重心音が深く長く崩れ記録が破れる。**引用レイヤー**: 各相を代表する実在のランドマーク文献（NINDS 1995、MR CLEAN 2015、GBD 2018 等）が相の交代時に静かに現れ、呼吸する滲み（shadowBlur）で揺らぎながら消える（うるさくしない）。**第II曲「消えゆくJカーブ」**: 用量–反応曲線（相対危険RR、用量7段階）を左上に描き、11〜14秒毎に用量の低→高を「用量掃引」フレーズとして鳴らす——**旋律の輪郭が曲線そのもの**（RR<1の保護域はドローン基準より低く純正に沈み、RR>1の有害域は高く＋微分音で濁る）。相が進むと窪みが浅くなり2020年に消失＝旋律が上昇一辺倒になる。曲線変形は4秒でなめらかに補間。**第III曲だけ独自の音律**: I・IIが半音階上の協和序列なのに対し、IIIは**スペクトル楽派の倍音列（純正律）**——根音を第8倍音とし、結合の強い概念ほど単純な整数比（8:12:16:10 = 1/1 : 3/2 : 2/1 : 5/4）を得る。急性期臨床＝「自然な流れ（血流）の回復」であり、エビデンスが確立するほど音は純正比にロックして唸りが消える。係争・逆転は**非調和性β**（±1.0%／2.2%）として比を歪ませ、倍音列ドローンに対し2〜4Hzの拍動する唸りを生む（第11・13倍音の中立音程＝臨床的不確実性の音）。1995年は根音の血栓溶解自身が唸り（2.2Hz、治療の不確実性）、2020年は再灌流・発症時刻・機能予後が **8:10:12＝純正長三和音** に収束——time is brainの鎖が三和音として鳴る唯一の瞬間。さらに拍は「時計」となり、door-to-needleの時間窓が閉じるように相のなかで加速し（×0.90→×0.60）、2拍ごとに低い鼓動が打つ。ドローンは第1・3・5倍音の開いた共鳴。**地図はDAG**（曝露→治療→媒介→アウトカムの4層に配置、因果の向きを矢印で描く。102辺すべてが前方向＝非巡回を検証済み）。**音**: 0.6秒を超える長い音は弓のように柔らかく立ち上がり膨らむ（violin風スウェル＋レリース）、短い音はソリッドな発信音のまま（緊張）。**マイク/カメラは撤去**し、観測の複雑性は「観測者の内なる気候」（緩やかな内部LFO）が駆動——展示での許可プロンプトも不要に。引用は水面から浮かび上がるように現れる（滲みが13→3へ収束、下線が左から伸びる、16秒の間隔、同時1件）。右上に目立たない帰還点 ⌂
- **`v3.html`（II'. 観測線）** — v2の走査線駆動リワーク。楽譜を空間化（x=有理数時間、y=音高、z=連符入れ子深度→奥行きパララックス＋音量）し、観測線が左からフェードイン→走査→衝突した粒子の運命を確定（発音はこの瞬間）→右端で消滅→静寂（疲労に比例した長さ）→次ページ。走査モード3種: STEADY（等速=基準グリッド）/ WAVER（集中力低下でよろめく）/ CANON（多重線が拍差で追走し弱く再観測=エコー）

## コンセプト
- コンピュータは「不可能な楽譜」を完璧に演奏できてしまう、という矛盾を逆手に取る
- システムはセリー（12音列＋48EDO微分音・強弱・アタックの音列）から演奏不可能な楽譜をリアルタイム生成し続ける
- 内部の「仮想演奏者モデル」（集中力・疲労パラメータ）がそれに挑み、タイミングの揺れ・音の脱落・音高の滑りとして失敗する
- 観客のマイク音・カメラの動きが楽譜の複雑度を上げ、演奏者の集中を削る → 崩壊のドラマが立ち上がる

## 構成要素
- 音: Web Audio API のサイン波のみ（48EDO＝八分音格子）＋マイク収音のグラニュラー具体音レイヤー（ffff級の強音イベント時に散布）
- リズム: 有理数時間の入れ子連符エンジン（5:4 の中の 7:6 など、複雑度で深度1〜4）
- 映像: Canvas 2D によるリアルタイム生成楽譜（五線・入れ子連符ブラケット・微分音矢印・強弱記号）。理想の楽譜は墨色、実際の演奏結果は赤でオーバーレイし、エラーは「染み」として残留。下層にマイクのスペクトログラム
- 入力: マイク（RMS・スペクトル重心→複雑度）、カメラ（フレーム差分の動き量→集中力の消耗）、タッチ/マウス

## 数理的枠組み（画面左下/右上の「数理」パネルにライブ表示）

セリー（音列）が作用する対象は6つ。すべての式は実測値が代入されて毎フレーム変化する。

| 対象 | 数理 |
|---|---|
| 音高類 | pc ∈ ℤ₁₂。変形はアフィン写像 x ↦ (εx + t) mod 12（ε=±1）＝二面体群 D₁₂ の作用。P/I/R/RI ＝ (ε, 読み順) の組 |
| 音高格子 | s ∈ ℤ₄₈（48EDO＝八分音格子）。s = 4((εr_k+t) mod 12 − 9) + 48·o_k + ι_k、周波数 f(s) = 220·2^(s/48) |
| 音列行列 | M_ij = (r_j − r_i) mod 12 の12×12行列（十二進表記）。行＝P形、列＝I形、逆読み＝R/RI。使用中の行/列と消費セルがハイライト |
| リズム | 連符比の選択列（第6のセリー）。発音時刻は ℚ 上の厳密な有理数 t = b + a/q（q = 分割比の積、例 ⟨7·5⟩ → q=35）|
| 演奏者 | 集中力の常微分方程式 Ċ = ρ − δ(X,M)、疲労 Φ̇ = 0.0035X − λ𝟙_fermata。誤差は Δt ~ N(0, σ²)、σ = (1−C)(0.35+0.65d/4)·90ms |
| 環境結合 | 複雑度は一次遅れ系 τẊ = −X + g(u)、g(u) = 0.12 + 3.5·RMS + 0.35·SC + 0.7·Motion（マイクRMS・スペクトル重心・カメラ動き量） |

## 操作
- 開始画面をタップ → マイク・カメラ許可（拒否しても内部シードで動作）
- 画面を押さえている間: フェルマータ（生成停止＋ドローン、演奏者の集中回復）
- 押さえたまま X軸: テンポ ×0.4〜1.8 / Y軸: 微分音グリッド（上=八分音、下=半音のみ）
- 右上ボタン: 数理パネル ON/OFF、具体音 ON/OFF、全画面、音 ON/OFF

## 実行方法
- ローカル: `node impossible_score/server.js` → http://localhost:4190 （マイク・カメラは localhost または HTTPS でのみ動作。file:// 直開きでは音は出るが収音不可）
- iPhone: GitHub Pages 等の HTTPS 配信で開く
