# SCORE FOR THE IMPOSSIBLE — 不完全な演奏機械

ニュー・コンプレキシティ（超複雑系）をコンセプトにしたインタラクティブ・サウンド＆ビジュアルインスタレーション。単一HTML・依存ライブラリなし。PC / iPhone Safari 対応。

## コンセプト
- コンピュータは「不可能な楽譜」を完璧に演奏できてしまう、という矛盾を逆手に取る
- システムはセリー（12音列＋48EDO微分音・強弱・アタックの音列）から演奏不可能な楽譜をリアルタイム生成し続ける
- 内部の「仮想演奏者モデル」（集中力・疲労パラメータ）がそれに挑み、タイミングの揺れ・音の脱落・音高の滑りとして失敗する
- 観客のマイク音・カメラの動きが楽譜の複雑度を上げ、演奏者の集中を削る → 崩壊のドラマが立ち上がる

## 構成要素
- 音: Web Audio API のサイン波のみ（48EDO＝八分音格子）＋マイク収音のグラニュラー具体音レイヤー（ffff級の強音イベント時に散布）
- リズム: 有理数時間の入れ子連符エンジン（5:4 の中の 7:6 など、複雑度で深度1〜4）
- 映像: Canvas 2D によるリアルタイム生成楽譜（五線・入れ子連符ブラケット・微分音矢印・強弱記号）。理想の楽譜は墨色、実際の演奏結果は赤でオーバーレイし、エラーは「染み」として残留。下層にマイクのスペクトログラム
- 入力: マイク（RMS・スペクトル重心→複雑度）、カメラ（フレーム差分の動き量→集中力の消耗）、タッチ/マウス

## 操作
- 開始画面をタップ → マイク・カメラ許可（拒否しても内部シードで動作）
- 画面を押さえている間: フェルマータ（生成停止＋ドローン、演奏者の集中回復）
- 押さえたまま X軸: テンポ ×0.4〜1.8 / Y軸: 微分音グリッド（上=八分音、下=半音のみ）
- 右上ボタン: 具体音 ON/OFF、全画面、音 ON/OFF

## 実行方法
- ローカル: `node impossible_score/server.js` → http://localhost:4190 （マイク・カメラは localhost または HTTPS でのみ動作。file:// 直開きでは音は出るが収音不可）
- iPhone: GitHub Pages 等の HTTPS 配信で開く
