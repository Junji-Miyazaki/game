# 設計書 — v2.6「知識のグラフ（The Epidemiology of Listening）」

超複雑系セリエリズムの「無調＝聴覚上のランダムノイズ」という罠を、
医学研究の営み（知識グラフの動態）を写すことで乗り越える版。
守るべき3つの一線をアーキテクチャの制約として組み込む。

## 0. 3つの一線 → 実装制約

| 一線 | 実装での担保 |
|---|---|
| **(1) 声は7つ以下・ラベル同期** | 概念は7つ（心臓病学）。各概念＝固有の音色（倍音）＋音域帯＋色。発音の瞬間、上部の知識グラフのノードと凡例ラベルが点灯し、対応が観客に学習される |
| **(2) データ→場／観測→質感の二軸分離** | **データ（知識グラフ）は「何が鳴りうるか」だけを決める**（どの音程・引力・反復）。**観測エンジンは「どう鳴り損なうか」を決める**（揺れ・脱落・休符・連符の複雑性）。複雑性は常に観測＝環境の質感であり、エビデンスの記号ではない |
| **(3) 必然性の主張の放棄・隙間と方法の開示** | 「データが音を正当化する」とは言わない。データセットは手作業の模型だと画面に常時開示（`MODEL v0 … 文献そのものではない`）。「地図は領土ではない」等を周期的に提示。隙間そのものを主題化 |

## 1. データ＝場（何が鳴りうるか）

- **概念（7声）**: 飽和脂肪 / コレステロール / 心疾患 / 喫煙 / スタチン / 塩分 / 糖。
  各々に固有の音色（第1,3,2,5,4,7,6倍音）と音域帯を割当＝ライトモチーフ。
- **共起＝主張＝音程**: エッジ（2概念の関係）を「発話」すると、その2声が**交互に鳴る音程**になる。
  確立したエッジは高頻度で反復（＝ミニマルなゲシュタルト、モチーフの刷り込み）、
  予備的・係争中のエッジは稀。
- **エビデンス階層＝協和度**: 各エポックで、パラダイムの中心概念（最も結合の強い概念）を
  重心音（根音）とし、そこへの結合が強い概念ほど協和的な音程スロット（完全5度・4度・3度…）、
  弱い概念ほど不協和（三全音・短2度）に配置。**場全体が中心を持つ「調性的な引力」を得る。**
- **係争・逆転＝微分音の傷**: contested/reversed のエッジ端点に48EDOの微分音デチューンを与え、
  場そのものに「うなり」を生む。**係争は複雑性ではなく微分音で表す**（制約2）。
- **時代（エポック）＝10年ごと**: 1950→2020をループ（途中入場に対応）。
  年代が進むと結合構造が組み変わり、重心音と協和配置が再編される。
  かつて協和していた音程が崩壊・反転する瞬間（飽和脂肪→心疾患の逆転劇）に音楽的ドラマが宿る。
- **撤回（Retraction）**: 係争エッジの発話がまれに撤回になり、築いた音符が赤い休符の連打で破綻。

## 2. 観測＝質感（どう鳴り損なうか）

現行の観測エンジンをそのまま継承。データには一切触らせない。

- 観測線が粒子と出会うと発音。**捕捉確率**（奥行き・注視）で漏れる＝淡い休符。
- 捕捉しても集中力に応じ**記録失敗**＝赤い休符、**タイミングの揺れ・音高の滑り**。
- **連符の入れ子深度＝環境（マイク・動き）**。会場が騒がしいほど観測が複雑に破綻する。
  ファーニホウ的複雑性は「不確実性の記号」ではなく**観測という行為の質感**として保つ。

## 3. 音楽性・調性/無調

- **調性でも無調でもない第三の状態**: 各エポックは重心音を持つ「場（モード）」＝
  ある種の調性感（引力）を持つが、平均律の機能和声ではなく、共起グラフが決める非機能的な旋法。
  確立＝協和へ収束、係争＝微分音のうなり、逆転＝崩壊。**協和と無調のあいだを、データの動態が旅する。**
- **リズム**: 発話は反復セル（タレア×コロル、拍の分解合成）で刷り込まれ（ミニマル）、
  その上に環境由来の入れ子連符（超複雑）が観測の質感として乗る。反復（既知）と複雑（未知）の衝突。

## 4. ビジュアル

- **上部＝知識グラフの俯瞰**: 7ノードを円環配置。現エポックのエッジを太さ＝結合強度、
  色＝状態（確立＝淡色 / 係争＝琥珀 / 逆転＝赤）で描く。発話中のエッジと両端ノードが閃く＝凡例と一体。
- **中央＝粒子場**: 概念色を帯びた粒子が右→左に流れ、観測線が捕らえる。二声のエッジは細い絆線で結ばれる。
- **背景＝巨大な年代**（1970…）が淡く漂う。
- **下部＝大譜表リボン**: 鳴った音を正確に記譜、漏れ／失敗を休符で記譜（データ＝場が音高、観測＝質感が記譜結果）。
- **常時＝開示テキスト**: データセットの出所と「これは模型である」旨。ブルーム＋動的視認性は継承。

## 5. 芸術的・社会的意味

作品は「聴覚化された疫学」＝**集合的で、誤りうる、自己修正する営みの俯瞰**になる。
仮説の生成（音程の発生）、合意の凝集（協和＋重心）、論争（微分音のうなり）、
逆転と撤回（崩壊・赤休符）、パラダイムの生死（エポック）。
だが作品は「医学はこう進歩した」と**主張しない**。データと音のあいだの写像はすべて作者の選択であり、
その恣意性と方法を開示することで、「**何かを知るとは、これだけの取りこぼしを伴う営みだ**」という
遂行そのものを上演する。サイコロは排除されたが、必然を騙ることもしない——隙間に音楽がある。

## 6. 限界（明記）

- データは**手作業の模型**（二次資料ベース）。真のMeSH共起は efetch でローカルJSONに焼く拡張余地を残す。
- 「飽和脂肪の逆転劇」は通俗化された物語である。忠実さとドラマの緊張は、方法の開示によってのみ引き受ける。
- 年代はループ。直線的映画ではなく、どの時代から入っても成立する気候として設計。
