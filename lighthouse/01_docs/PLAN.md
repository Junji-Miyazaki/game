# LIGHTHOUSE（仮題）— 計画書

作成: 2026-11-06（リーダー Opus 5.5）。会話の中で試作を8回作り直して決めた内容をまとめる。試作の本体は `07_lab/proto_v9/`（縦向き。公開ページは直下の `index.html`、自動プレイは `node 07_lab/proto_v9/sim.js auto 4`）。横向きの v8 は `07_lab/proto_v8/` に残す。
品質の基準は LANDER（`../lander-1.1/`）。コードは写してよいが、このフォルダの中で独立させる（LANDER から import しない）。

## 1. 要点
- **横スクロール**。鳥の群れが自動で右へ飛び、人工物に体当たりして壊し、得点を重ねる。最後に岬の灯台を倒す。
- 空気感は「人工物に対する鳥の怒り」。曇った灰色の空と黒い群れ（Hitchcock『鳥』の空気感だけを参考にする。名前・題名・場面は借りない）。
- 鳥は当たると減る。**数・守り・攻撃**のどれを強化して補うかが判断の中心。
- 建物は**強度を持つ四角いマス**でできていて、下を崩すと**物理的に崩れ落ちる**。
- 途中に**中ボス2体**（時計塔・給水塔）、最後に**灯台**。そこではスクロールが止まり、群れが上空で輪を組んで回りながら四方から突っ込む。

## 2. 1回の遊び（1ラン）
1. 村から出発（40羽）。自動で右へ進む（試作は 100px/秒）。
2. 区間を順に抜ける：村 → 町 →【中ボス：時計塔】→ 都市 → 工業地帯 →【中ボス：給水塔】→ 岬 →【灯台】。
3. 壊したマスがポイントになり、その場で強化に使う。
4. 群れが尽きたら終わり。灯台のランプを壊せばクリア（LIGHT OUT）。
- 試作の所要時間：強化し続けて約110秒で灯台撃破。強化しないと時計塔（約30秒地点）で尽きる。

## 3. 群れの動き
| 場面 | 動き |
|---|---|
| 道中 | 空の中ほど（中心は地面から約180px上）を、V字 → 波打つ帯 → 球 の編隊に約7秒ごとに組み替えながら飛ぶ。大きさは約11秒周期で 0.6〜1.4 倍に呼吸する。1羽ずつ揺れを付け、揃いすぎないようにする。 |
| 道中の攻撃 | 1羽ずつ編隊を抜け、前方の建物へ翼をたたんで急降下。根元寄りを多めに狙う（倒すと得になるため）。当たったら編隊へ戻る。 |
| 包囲（中ボス・灯台） | スクロールが止まり、相手の上空で横長の輪を組んで回る（3重のレーン、手前の鳥は大きく奥は小さく描く）。1羽ずつ、いる位置から一番近い面へ 0.5〜1.6 秒間隔で突っ込む。3割強は根元を狙う。 |
| 仲間の合流 | 道中の決まった地点で、5〜11羽の小さな群れが画面の外（上 4割・右 3.5割・左 2.5割）から飛んできて合流する。合流前は少し薄い色。試作では平均1.6秒で合流。 |
| クリック／タップ | その場所へ群れが集まって縮み（約0.4倍）、近くの建物を集中攻撃する（約2.5秒）。根元を指せば倒せる。何もしなくても自動で進む。 |

- 見た目：鳥は線1本の「へ」の字（5点の折れ線）。目やくちばしは描かない。鳥だと分かるのは羽ばたきの動きで伝える。急降下では翼をたたんで細くなる。
- 鳥は1羽ずつ体力を持つ（試作：2＋守り）。壊し切れなかった時（マスのほうが硬かった時）に1減り、跳ね返る。壊し切った時はそのまま突き抜ける。

## 4. 建物と崩れ方
- 建物はマス（試作 6px）の集まり。マスごとに素材と強度がある。色の濃さで残りの強度を表す。
- 当たって壊し切ると、余った力が隣のマスへ連鎖する。

### 崩れる仕組み（毎回、壊れた建物だけ確かめる）
1. **地面とつながっているか**：根元からたどって、つながっていない塊は落ちる。
2. **その段が上を支えきれるか**：途中の段が次のどちらかになると、そこから上がひと塊で崩れる。
   - 元のマス数に対する残りの割合が素材の限度を下回った。
   - 上の重さの中心が、その段の左右の端からはみ出した（片側を削るとそちらへ傾いて倒れる）。
- 崩れた塊は回転しながら落ち、地面や他の建物に当たると砕けて瓦礫になり、地面に残る。当たった建物も壊す（ドミノ）。下にいる鳥は体力を失う。
- 崩れて砕けたマスにも得点が入る（壊した時の約8割）。

### 素材（試作の値）
| 素材 | 強度 | 崩れる限度 | 主な場所 |
|---|---|---|---|
| 藁 | 0.35 | 5割 | 村の屋根 |
| 木 | 0.8 | 4.5割 | 小屋・家の壁 |
| レンガ | 2 | 4割 | 町 |
| ガラス | 1.4 | 4割 | 窓、ガラスのビル |
| コンクリート | 3.4 | 3.5割 | 都市 |
| 鉄骨 | 6.5 | 2.5割 | 鉄塔 |
| 石（時計塔） | 22 | 3.5割 | 中ボス |
| 文字盤 | 60 | 3割 | 時計塔の急所 |
| 鉄の脚（給水塔） | 45 | 3割 | 中ボス |
| タンク | 40 | 3割 | 給水塔の急所 |
| 灯台の壁 | 60 | 4.5割 | 最後 |

- 攻撃力の初期値は 1.6。時代が進むほど硬い。

## 6. 強化（その場で使う）
| 強化 | 効果（試作） | 効く相手 | 費用 |
|---|---|---|---|
| 仲間を呼ぶ | +8羽 | 脆い建物の数 | 25 から 1.55 倍ずつ |
| 守り | 全員の体力 +1 | 硬い物（鉄骨、中ボス） | 40 から 1.55 倍ずつ |
| 攻撃 | 攻撃力 +0.8（足し算） | 突き抜けやすくなる＝減りにくい | 45 から 1.55 倍ずつ |
- 攻撃を掛け算（×1.5）にすると後半に強くなりすぎ、灯台が一瞬で倒れたので足し算にした。
- 試作では道中もボタンで買う。本編での買い方（常時のボタン／中ボス後の選択画面）は §10 で決める。

## 7. 画面・操作
- 論理解像度 **360×640（縦長）**、スマホは縦持ち（2026-11-06 ユーザー決定。LANDER と同じ向き）。進む向きは横（右へ）のまま。
- 配置（試作 v9）：上 0〜110 に得点・群れのカード、道のりバー、区間名またはボスの残りバー。中央が空と地面（地面 y=500）、下 532〜640 の角丸シートに強化カード3枚。速さと音の丸ボタンは右上。UI は半透明の角丸の板、アクセントは琥珀色1色。
- 灯台：ランプが消えたら「LIGHT OUT」の帯だけ出し、崩しきる（立つマスが最初の 25% 以下）まで包囲を続ける。消灯後は残りの強度を 0.35 倍にする。
- 縦画面で横に見える幅は 360px。道中の群れは画面の左寄り（x=165）、包囲中はボスを画面中央に止める。編隊は横を 0.7 倍、縦を 1.4 倍にして縦長に広げる。
- 操作：タップ／クリックで集合と集中攻撃。強化は下のボタン。キーボード操作は P1 で決める。

## 8. 演出と音
- 空：曇った灰色の単色。遠景に低い街並みのシルエット（区間で形を変える）。地面は村だけ草色。
- 鳥：黒い線。仲間の合流は薄い色。落ちる鳥は灰色で回転しながら落ちる。
- 音の方針（2026-11-06、ユーザーが Hitchcock『鳥』を参照）：旋律の BGM は置かず、羽音の層と電子音の鳴き声で緊張を作る。試作 v9 で実装済み。以下は当初案。
- 音（WebAudio で生成、素材ファイルなし。LANDER の music.js の構成を写す）：群れの羽音の層（数で厚くなる）、体当たりの鈍い音、素材ごとの壊れる音（藁・木・ガラス・石・鉄）、崩落の地響き、包囲中の旋回音、撃破と LIGHT OUT のジングル。BGM は低く不穏なドローンを区間ごとに変える。
- **線引き**：人は出さない（無人の夜明け前、または廃墟の街）。飛行機や、2本並んだ高層ビルなど、実際の事件を連想させる形は使わない。

## 9. 既存作との距離
- 「鳥が当たって構造物が物理で崩れる」点は Angry Birds の印象に近い。違い：パチンコで狙わない、群れが自動で突撃する、数・守り・攻撃を強化しながら横へ進む、豚がいない、最後の相手は灯台。
- 「強度を持つマスを削る」型は放置系（Auto Drill: Galaxy など）でよくある型。見た目・画面配置は寄せない。
- Hitchcock『鳥』は空気感だけを参考にする。

## 11. 不採用にした案（経緯）
| 案 | 理由 |
|---|---|
| 1羽を操作して撃つ縦シューティング | 鳥がミサイルを撃つのは不自然 |
| 放置系（閉じている間も進む） | 鳥が減って補う判断のほうが面白いと判断し、ラン型にした |
| 灯台を下から登って崩す | 下が無いのに浮いて見える、鳥の大きさに対して灯台が小さい |
| 地上の灯台が鳥を撃ち落とす（逆） | 依頼の主旨から外れる、METEOR と同じ型、鳥を撃つ後味 |
| ひびの線で壊れ具合を表す | マスが崩れるほうが分かりやすい |
| 群れごと低空で突っ込む | 地面すれすれに固まって見えた。編隊から1羽ずつ抜ける形にした |
| 野生の群れが空中で待つ | 不自然。画面の外から飛んできて合流する形にした |
