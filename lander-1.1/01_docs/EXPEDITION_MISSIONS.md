# EXPEDITION ミッション一覧（v1.2 試作用・段階0）

2026-10-26 作成（リーダー Opus）。前提は PLAN §7m。
- 操作は全ミッション共通（左右回転＋メイン噴射）。
- 解放はツアー中のミッション POD。
- 動機は★のコンプリート。POD の得点は 0。

## 前提となる現行の数値（v1.1 beta.4）
- 推力 5.2 px/s²。月の重力は 0.25 px/s²、TERRA は 0.615 px/s²（重力は推力の 5〜12% と小さい）。
- 着地の安全範囲（即成功）：縦 ≤22 px/s、横 ≤13、傾き ≤28°、回転 ≤20°/s。即失敗の上限：縦 45、横 26、傾き 55°、回転 40°/s。
- 既存の仕組みで使えるもの：接地と離陸（L1）、輪、特典、視界、熱、風、動くパッド、隕石、シールド。

## 共通方針
- **重力の下限は 0.03 px/s²**。実重力をそのまま当てるとほぼ 0 になるため。ごく弱く「下」を残し、操作の手がかりにする。
- **無重力系の新しい技は「逆噴射で止まる」**。機体を進行方向と逆に向けて噴射する。ツアーでは「上に噴いて減速」で足りたので、これが上達の伸びしろになる。
- **1ミッションは 30〜90 秒**。ツアーの1ステージと同程度。
- **★3 の形は全ミッションでそろえる**。★1 ＝ 目的達成。★2 ＝ ミッション固有の上級条件。★3 ＝ PERFECT（または高精度）。

## 試作の順番と理由
1. **#1 往復（PHOBOS）**：既存の接地・離陸を流用でき、新しく作るのは採取とドッキングだけ。「着陸の後にもう一段ある」体験がツアーとの違いとして一番分かりやすい。
2. **#2 間欠泉（ENCELADUS）**：操作は今のまま、環境だけが新しい。安く作れる。
3. **#3 タッチ・アンド・ゴー（RYUGU）**：無重力と逆噴射を最初に試す。#4 の土台にもなる。
4. **#4 錨（67P）**：#3 の結果を見て判断する。
5. **#5〜#8**：上の試遊の反応を見て選ぶ。#5 と #6 は小さいので、合間に試作してもよい。

## 試遊で確かめること（残すかどうかの基準）
- 説明なしで 30 秒以内に、何をすればよいか分かるか。
- スマホの3ボタンで無理なく操作できるか。
- ツアーの着陸とは違う楽しさがあるか。
- もう一度やりたくなるか（★2・★3 を狙いたくなるか）。
