## 01 SAMPLE RETURN
流れ: **母船のドッキングベイに係留した状態で開始**（最終ドッキングと同じ位置・直立姿勢。燃料満タン）→ **TAP TO RELEASE**（点滅表示。キャンバスのどこをタップ / 推力ボタン / Space・↑ で解放。タイマーによる自動解放なし。係留中の待機では何も失わず、ライフを失うのは解放後のみ。解放で母船の水平速度を引き継ぎ、下へ 18px/s で自動で離れる。約1秒は操作不可、その後操作可）→ 琥珀色の SAMPLE SITE（平ら）に着地 → 2.0 秒静止（円ゲージ。推力を入れる/離陸するとゲージはゼロに戻る）→ SAMPLE ACQUIRED → 離陸 → 母船へ戻る。
**ゴースト**: 離れている間、母船のベイに機体の破線アウトライン（直立）を常時表示。母船と一緒に動く＝戻るべき形と位置。枠内・相対速度 ≤10 px/s・傾き ≤20° が揃うと青緑に点灯し、0.25 秒それが続くと MISSION COMPLETE（吸い込み演出）。
失敗: 墜落（v1.1 と同じ閾値）/ 燃料切れで 5 秒流れる（LOST CONTROL、下の「燃料切れ」）/ 画面外。**母船の船体・ドッキング枠への接触は失敗にならない**: 固体として扱い、相対速度 >10 px/s の接触は法線方向に反発（反発係数 0.35）+ 回転 ±15°/s + 0.3s の画面揺れ + 衝突音 + 'BUMP' 表示、船体の外へ押し出す（前回位置→現在位置を 2px 刻みでスイープするので高速でもすり抜けない）。枠の入口（下側）は開いている。帰路は枠が固体なので、母船の真下へ回り込んで入る。母船は開始時から飛んでいる（輪は採取後に琥珀色に点灯、枠内で速すぎ・傾きすぎると赤字で理由）。
**PRACTICE / MISSION**: 起動時はメニュー（PRACTICE / MISSION の2ボタン、BEST スコアと累積★1-3 を表示）。URL `?mode=practice|mission` でメニューを飛ばせる。
- PRACTICE: 'UNLIMITED RETRIES · NO STARS'。失敗しても R / RETRY で即やり直し、スコア・★は保存しない（HUD に PRACTICE）。メニューのチェック **START AT SITE**（降下を飛ばして採取地点から）/ **START NEAR DOCK**（採取済みで母船の真下から帰路のみ。両方ONなら NEAR DOCK 優先）。URL `site=1` `near=1`。
- MISSION: '3 LIVES · STARS & SCORE'。HUD 右上にライフ（小さな機体アイコン×3）。失敗 → ライフ -1 → 'LIFE LOST' を 1.6 秒表示 → 母船係留スタートへ自動で戻る（母船の位相は従来どおり ph0 から）。0 ライフ → 'MISSION FAILED'（RETRY MISSION＝新しい3ライフ / MENU）。**ミッション中に R を押す（解放後）とライフを1つ失う**（無料リトライの抜け道を塞ぐ。係留中の R は無料）。
- スコア = (1000 + 燃料% ×10 + 着地ボーナス[PERFECT 300 / その他 100] + 時間ボーナス max(0, 1500 − 10×秒)) × ライフ倍率（残り3 ×1.0 / 2 ×0.8 / 1 ×0.6）。勝利時は 'MISSION COMPLETE'・残りライフと倍率・SCORE・★（新規に NEW）・BEST・RETRY MISSION / MENU。
- **タイムトライアル**: 時間 = 解放 → ドッキング成功（成功した命の分だけ。ライフを失うと次の命で 0 から。係留中は進まない）。解放後に HUD 右上へ mm:ss.t を常時表示（PRACTICE も表示するが保存しない）。結果画面に TIME / TIME BONUS、自己ベスト更新で 'NEW BEST TIME'。メニューに BEST SCORE / BEST TIME。ベストタイム（MISSION 勝利のみ・最小値）は `lander11.exp.sample_return.besttime`（秒の数値）、スコア・★は `...best`（別キー）。
- **オフサイト着地**: SAMPLE SITE 以外でも、傾斜 ≤10° かつ SAFE 内なら grounded（採取なし・失敗なし）。推力で離陸（本編 L1 の grounded と同じ規則）。急斜面・強い衝撃は従来どおり失敗（STEEP GROUND / HARD IMPACT）。地形に平地 2 か所（x≈28-92, 300-350）と急な岩（x≈130）を追加。機体の真下の地面に傾斜マーカー（青緑 ≤5° / 琥珀 ≤10° / 赤 >10°）を高度 130px 以内で表示。
- ★: ★1 完了 / ★2 ドッキング時の燃料 ≥30% / ★3 採取した着地が PERFECT。累積（和集合）と最高スコアは localStorage `lander11.exp.sample_return.best` のみ（MISSION 勝利時だけ更新）。旧 `...attempts` は起動時に削除。デバッグパネルの RESET RECORD で記録消去（スコア・ベストタイム両方）。
R か RETRY で即やり直し。
速度ベクトル矢印: 採取前は地面に対する速度、採取後は**母船に対する相対速度（REL）**。機首方向の点線が矢印と逆向きなら逆噴射の向き。デバッグで OFF 可。

URL パラメータ（共通 + 固有）: `g=0.04 thrust=5.2 ang=28 damp=0.82 drag=0 fuel=100 rcs=2.5 vec=1` / `ms`（母船の最大速度 px/s, 既定9）/ `ph0`（母船の開始位相 rad, 既定-1.2）/ `hold`（採取秒, 既定2.0）/ `ring`（枠の半径 px, 既定17）/ `dbg=1`（パネル初期表示）/ `test=1`（`window.__auto.run({ph0})` の検証用自動操縦。姿勢と降下中の横速度を理想的に与えるので人間の腕前の保証ではない。局面ログ: docked → descent → sampling → return → win の5局面。`__auto.bump({speed,ox,dy})` = 母船への衝突テスト（墜落せず続行・すり抜けなし）、`__auto.score()` = メニュー/練習/ミッション/ライフ喪失/MISSION FAILED/永続化の検査、`__auto.five()` = ミッション通常クリア5本、`window.__flow` = begin(mode,opts)・tap(x,y) のテスト用口。test=1 は帰路の横合わせも理想化）。

## 02 GEYSER RUN（ENCELADUS）
流れ: 上から進入（開始待ち: **TAP TO START** — タップ / 推力ボタン / Space・↑。待機中は何も失わずタイマーも止まる）→ 噴気の頂上付近に出る光る**試料**を通過して取る（チャイム）→ **試料が1つ以上**でパッドが開く → 噴気の間のパッドに着地 = 完了。ヒント: 'FLY THROUGH THE PLUMES · GRAB A SAMPLE · LAND ON THE PAD'。
- **世界**: 氷の白青の地表 + 暗い虎縞 + 土星（大）。重力 0.066 px/s²（実 g 0.113 → ゲームの sqrt 写像）、抗力なし、推力 5.2 / 回転 28 / 減衰 0.82 / RCS 2.5 / 燃料 100 は #1 と同じ。
- **噴気 3 本**（x=52 / 150 / 308、周期 11 / 12 / 13 秒（噴出の合間に 6〜8 秒の静かな時間）、最初の噴出 6.5 / 11.5 / 1.5 秒、強さ係数 0.92 / 1.08 / 1.0）。噴出の **1.2 秒前**から口に霜が舞い（徐々に濃く）、ヒス音。噴出 = 立ち上がり 0.5 s → ピーク 1.8 s → 2.7 s で消える（**計 5.0 s**）。高さ 290px の柱。
- **噴気の力**: 柱の内側（半幅 11→20px、高さとともに広がる）で上向きに **口で push（既定 13）× 係数（≈ 10〜12 px/s²）→ 頂上で 3 px/s²** へ直線的に減り、中心ほど強く、消えるにつれ弱まる。加えて横ゆれ（〜±4 px/s²）とスピンの乱れ（〜±5°/s²、減衰があるので ±数十°/s）。**墜落ではない**。
- **噴出口**: 噴出中に口へ降りると墜落でなく**押し返す（BUMP: 上向き速度 + 横へ + 回転、画面揺れ + 音）**。噴出していない口には着地できる（平ら）。接地中に噴いたら持ち上げられる（'VENT ERUPTED'）。
- **試料**: 噴出の立ち上がり（0.5 s）後に頂上付近（高さ 86%）へ出現 → 噴出中はその場に漂い、噴出が終わってから **6 秒残る**（その間 重力 g×10 でゆっくり落下 + 横へ 1.6px/s ドリフト）→ 点滅して昇華（消える）。**残り時間リング**（時計回りに縮む。残り 2.5 s 未満で琥珀、1.5 s 未満で点滅）。取得半径 14px。取れずに消えた試料は、その噴気の**次の噴出で再出現**（各噴気で取れるのは 1 回だけ・最大 3）。出現前は**予告マーカー**（点線の輪）が常時うっすら、霜の前触れで濃くなる。最初の噴出より前には出ない。
- **パッド**（x=200-260、噴気 2 と 3 の間）: 試料 0 の間は **LOCKED**（赤・鍵）。降りても grounded のみ（得点なし・失敗でもない。推力で離陸）。1 つ以上で緑に点灯し、安全着地した瞬間に MISSION COMPLETE（グレードは game.js の表）。
- ★1 = 完了（試料 ≥1 + パッド着地）/ ★2 = 3 つすべて / ★3 = パッドに PERFECT。得点 = (1000 + 燃料%×10 + 着地ボーナス[PERFECT 300 / 他 100] + 時間ボーナス) × ライフ倍率（共通）。試料数による加点はなし（★2 のみ）。
- 失敗: 地面への墜落（v1.1 と同じ閾値、急斜面含む）/ 画面外 / 燃料切れで 5 秒流れる（LOST CONTROL）。オフサイト着地（傾斜 ≤10° = grounded）と足元の傾斜マーカーは #1 と同じ。時間 = タップで開始 → パッド着地（ライフ喪失で 0 から）。
- 調整（デバッグパネル / URL）: `push`（口での押し px/s²、既定 13）/ `hp`（柱の高さ px、既定 290）/ `ph0`（全噴気の位相ずらし秒）+ 共通 `g thrust ang damp drag fuel rcs vec`。`?mode=practice|mission`、`dbg=1`、`test=1`。
- テスト（`?test=1`）: `__auto.physics()` = 噴気の押し（口付近 9〜14・頂上≈4・柱の外 0）/ 前触れ / 周期・噴出 5.0 s / 口でのバウンス / 接地中の噴出 / 試料（`linger`: 出現・噴出後 6 s 残る・落下・期限切れ・次の噴出で再出現、`sample`/`respawn`: 取得・1 回だけ・3 本）/ パッドのロック / 失敗 3 種、`__auto.score()` = メニュー〜ライフ〜永続化〜R キー、`__auto.five()` = 位相 6 通りの通常クリア（試料 1 / 3 個。3 個は噴出中は柱の外で待ち、終わってから残った試料を取りに行く。`run({trace:[]})` で位置・燃料のログ）。`score()` にブリーフィング（?・選択直後・SKIP 保存）の検査を含む、`__auto.run({mode, ph0, want})`。自動操縦は姿勢と横速度を理想化（人間の腕前の保証ではない。噴気・衝突・試料・ロックは本物の物理）。

## 03 TOUCH-AND-GO（RYUGU）
流れ: **左上（x=60, y=110）で開始待ち**（**TAP TO START**。タップ / Space・↑。待機中は何も失わずタイマーも止まる）→ 開始で vx=+8・vy=+16 px/s（右下へ流れながら降りる = 横と縦の流れを止めるのが課題）、すぐ操作可 → 岩の間の**目標円**（x=187、半径 18px、平らな空き地）に **合成速度 ≤8 px/s・傾き ≤20°** で触れると自動で採取（弾丸発射の閃光 + 砂の飛散 + 「ドン」）→ **小さく弾んで（上向き 14 px/s）0.9 秒で自動的にほぼ静止**（この間は操作なし、重力も打ち消す、傾きも 0 へ）→ 中央下寄りに **'SAMPLE OK' + 'LIFT OFF!'**・機体の上に上向きの山形・機体の横に残り秒・3連の警告音 → **合図から 9 秒以内に安全高度の線（目標の地面から 104px 上）より足元を上げる** = **CLEAR!**（時間・燃料はここで確定）→ 機体が自動で直立し、真上へ加速して画面の外へ去る（'LEAVING RYUGU…' → 'SAMPLE SECURED'、文字は機体の通り道と反対側、計 2.8 秒、計器と OUT OF RANGE 警告は隠す、R は無視）→ 結果。2026-11-03 ユーザー指摘「着地で終わりだと思いがち」「ゴールが低すぎ」への対応。**母艦は置かない**（母艦との発着は #1 PHOBOS だけ。#1 と似ないように。2026-11-03 ユーザー決定。一時的に入れた「母艦から切り離し・母艦へ自動帰還」は撤去）。
- **接触の規則は一つ**:「8 px/s 以下ならどこに触れても壊れない」。目標円 = 採取 / 岩（足元の傾斜 >10°）= 法線方向に押し返す（BUMP、反発 0.5、外向き最低 3 px/s）/ 平地 = 接地（grounded、推力で離陸）。8 px/s を超えると: 目標円では跳ね返る（'TOO FAST · NO SAMPLE'、採取なし・墜落なし。BOUNCE 上限を超えると HARD IMPACT）、岩では従来どおり墜落（STEEP GROUND など）。目標円で傾き >20° も跳ね返る（'TILTED · NO SAMPLE'）。採取後に目標円へ触れても跳ね返るだけ。
- **離脱**: 合図の後、砂ぼこりが目標から昇り、制限時間ちょうどで線に届く。線の上に緑の帯と 'GOAL ↑ CLIMB ABOVE THIS LINE'。残り秒は機体の横（2.5 秒未満で赤）。時間切れ = 'CAUGHT IN DEBRIS'。何もしなければその場に留まる（2 秒で 1.5px 未満しか動かない）。理想的な離脱（直立で全推力、静止から）で約 6.0 秒、余裕 約 3.0 秒。
- **世界**: 重力 0.03 px/s²（共通方針の下限）、抗力なし、他は #1・#2 と同じ。暗い炭色の礫の地表、岩 6 個（目標の左右に大小）、太陽のにじみ、遠い地球。**地表は小天体らしく円弧**（中心 x=187・半径 450px。目標は弧の頂上で平ら、両端は 35〜41px 下がる。両端ほど暗い陰影 + 地平線の淡い光。重力の向きは真下のまま。見た目のための変更で、弧の端は傾斜 >10° なので触れると岩と同じく押し返される）。
- **HUD**: 左上を SPEED（合成速度、≤8 緑）/ TILT（≤20° 緑）/ SPIN / ALT に置換（標準 HUD の DESC/DRIFT は 22/13 基準でこのミッションに合わないため）。機体が地面から 140px 以内では機体の横に速度（≤8 緑、PERFECT 範囲で金 + 'PERFECT'）。目標の上に 'TARGET ≤ 8 px/s'（機体が近いと薄く）。足元の傾斜マーカーは目標円の中は常に青緑。
- ★1 = 完了 / ★2 = 目標の**中心**（ずれ ≤5px）に触れる / ★3 = **PERFECT タッチ**（速度 ≤3 px/s・傾き ≤5°・回転 ≤6°/s）。得点 = (1000 + 燃料%×10 + [PERFECT 300 / 他 100] + 時間ボーナス) × ライフ倍率（共通）。時間 = 切り離し → 線を越える。
- 調整（デバッグパネル / URL）: `vtouch`（採取の速度上限、既定 8）/ `leave`（LIFT OFF の合図からの制限秒、既定 9）/ `alt`（安全高度 px、既定 104）+ 共通。`?mode=practice|mission`、`dbg=1`、`test=1`。
- テスト（`?test=1`）: `__auto.physics()` = 採取（中心・PERFECT・斜めの合成速度・傾き 8° は PERFECT でない）/ 速すぎ・傾きすぎの跳ね返り / 50 px/s は墜落 / 岩 5 px/s は押し返し・15 px/s は墜落 / 平地の接地と離陸 / 採取後の自動静止（弾みの高さ 3〜20px・操作無効・合図で操作復帰・その場に留まる）/ 離脱の時間切れと成功 / CLEAR 後の去る演出（時間が止まる・演出中は結果なし・機体は真上へ上がり横にずれない・直立・画面の外で消える・その後に勝利）/ 失敗 2 種、`__auto.score()` = メニュー〜ライフ〜永続化〜R キー〜ブリーフィング、`__auto.five()` = 接触速度とずれ 6 通りの通常クリア。自動操縦は姿勢と横速度を理想化（人間の腕前の保証ではない）。
