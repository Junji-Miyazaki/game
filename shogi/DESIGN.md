# CYBER SHOGI — 電脳将棋 設計ドキュメント

idea.txt(サイバー将棋)の評価・リサーチ・再設計・実装計画。2026-07-14。

---

## 1. idea.txt の評価(忖度なし)

### 強み
- **テーマの核が本質的に将棋と噛み合っている**: 「敵駒を奪って自軍として使う」持ち駒ルールは、そのまま「ハッキングによる乗っ取り」と読み替えられる。テーマの後付けではなく構造的な一致。これが本案最大の資産。
- 駒アイデアの一部(ハッカーのバックドア、衛星の端ワープ、DDoS)は直感的でフレーバーが立っている。

### 致命的な問題: システム過多
原案は **AP制+経験値レベル+コンボ+カード5枚+エネルギー/データ資源+遅延/帯域+セキュリティレベル4段+動的盤面+ダイス戦闘+勝利条件3種** を同時に載せている。リサーチでも「新規コンセプト4つ超で初回プレイが崩壊」「複雑な新駒の識別困難がチェス変種失敗の主因」と裏付けられた。具体的には:

1. **「コンパクト・短時間・繰り返し」と正面衝突**: 15×9盤+資源2種+AP管理は1局30分超コース。
2. **ダイス戦闘は将棋マニアを確実に離脱させる**: 完全情報の読み合いこそ将棋系の快楽。戦闘のたびに乱数判定が入ると「読み」が無意味化する。
3. **AIの「最適手提示」・量子駒の重ね合わせ**: 実装・UI・対人での検証すべてが高コストで、面白さへの寄与が不明。
4. **勝利条件3種**: 9×9ですら評価関数が壊れる。プレイヤーの目標が拡散する。

### 結論
「捨てる勇気」が必要。**核=持ち駒ルールのサイバー再解釈**だけを残し、乱数は「ラン構造(強化ドラフト・シード)」側に隔離、**盤上は完全情報**を維持する。

## 2. リサーチ要約(2023–2026)

- **Shotgun King / Pawnbarian / Passant**: チェス×ローグライクは確立ジャンル。共通項は「盤上は完全公開・自己責任のミス」「1戦5分前後」「戦闘間の強化ドラフト」。
- **Balatro(2024)**: 「あと1回」を誘う密なフィードバックループと短いラン。個人開発でも設計が良ければ売れる実証。
- **Onitama**: 「ランダム性はセットアップに限定し、その中は完全情報」— 将棋/チェス勢とローグライク勢の折衷点として機能する設計原則。
- **Wordle型デイリー**: 全員同一シード・1日1回・結果共有が habit loop の定番型。
- **5五将棋アプリ**: 平均対局2分。日本市場で短時間将棋の需要は実証済み。
- **失敗パターン**: ルール過多、駒の動きの識別困難、既存ゲームからの心理的距離。

→ 本プロジェクトの設計指針: **5五将棋(習得済み資産の流用)× ローグライク3連戦(短時間ラン)× 乱数はドラフトとシードのみ(盤上完全情報)× デイリーシード(再訪動機)**。

## 3. 再設計: CYBER SHOGI v1 仕様

### コア
- 盤: **5×5(5五将棋準拠)**。初期配置・二歩・最奥段歩打ち禁止・持ち駒ルールは本家準拠。
- 1局 2–5分 × 3ステージ = **1ラン 10分前後**(暇つぶし要件)。
- 敵駒を取る=**ハッキング乗っ取り**(HACKEDグリッチ演出+持ち駒化)。テーマとルールの一致点を演出で最大化。

### 駒(将棋の動きは変えない=学習コストゼロ)
| 将棋 | サイバー名 | 成 |
|---|---|---|
| 玉 | CEO | — |
| 飛 | AIコア | AGI(竜) |
| 角 | 衛星 SAT | SAT+(馬) |
| 金 | ファイアウォール F/W | — |
| 銀 | ハッカー HCK | APT |
| 歩 | bot | BOT+(と金) |

### ラン構造(ローグライク)
- STAGE 1 野良サーバ(敵:飛車なし・探索深さ2・評価ノイズ大)
- STAGE 2 企業ファイアウォール(フル編成・ノイズ小)
- STAGE 3 国家中枢システム(フル+持ち駒bot・深さ3・ノイズ0)
- クリアごとに**サイバー強化を3枚から1枚ドラフト**(乱数はここだけ):
  増援BOT / AI覚醒(飛が竜で開始) / 衛星軌道リンク(角が左右端をワープ周回=唯一の駒能力改変) / DDoS+1(敵1体2手停止・手番不消費) / バックアップ復元(局1回、奪われた駒を自軍手駒へ) / ゼロデイ(敵bot初期消去)

### リプレイ動機
- **DAILY RUN**: 日付シードで強化提示・AIノイズを固定。全員同条件のスコアアタック(Wordle型)。
- **スコア+ランク(S–D)**: 乗っ取り価値+ステージボーナス+速度ボーナス。
- **棋譜LOG**: 全手記録・表示(マニア向け。将来は再生・共有)。
- 敗北=ラン終了(数分の損失で済む → 即RETRY導線)。

### マニア心をくすぐる点
- 盤上は乱数ゼロの完全情報。負けは常に自分の読み負け。
- 5五将棋の定跡感覚が通用しつつ、強化ドラフトが毎回定跡を崩す(Onitama原則)。
- DDoSは「手番を消費しない」ため、詰み手順に組み込む「DDoS込みの詰将棋」という新しい読みが生まれる。
- 全敵駒凍結によるSYSTEM LOCKDOWN勝ち等の裏勝ち筋。

### プロトタイプでの簡略化(明示)
- 昇格は自動(不成の選択なし)
- 打ち歩詰め判定なし
- 敵AIは negamax+alpha-beta(深さ2–3)+段階別ノイズ
- DDoS凍結中の駒は利きも失う=その駒による王手も一時消滅(「攻撃機能ごと停止」という意図的仕様。バランスは要観察)
- DDoSチャージは局ごとではなくラン全体での使い切り

## 4. 成立性の評価(質問への回答)

- **ゲームとして成立するか**: する。ベースが5五将棋(競技実績のある完成ルール)なので、変種で最も危険な「ルールの穴」リスクが最小。追加要素は6強化+凍結のみで直交性が高い。
- **マニア心**: 完全情報+棋譜+デイリーシード+速度ボーナス(手数最適化)で担保。ただし本気のマニア向けには**敵AIの棋力が最終的なボトルネック**(後述のロードマップで対応)。
- **短時間の暇つぶし**: 1局2–5分、1ラン10分、負けても即リトライ。要件充足。
- **繰り返し参入**: デイリーシード+強化ドラフトの組合せ変化+ランク到達目標。v1で最低限の輪は閉じている。強化プールの拡張(6→20種)が今後のリテンションの主レバー。

## 5. 実装計画(ロードマップ)

### v1 — 基盤プロトタイプ(完了)
単一HTML。5五将棋エンジン、negamax AI(深さ2–3)、3ステージ+強化ドラフト6種、DAILY/FREE、スコア/ランク、棋譜、WebAudio SE、ネオンUI。
※v1の盤上は将棋そのもの(「名前を変えただけ」問題)。これを解くのがv2。

### v2 — NETWORK PROTOCOL(完了)
「サイバーであることがルールとして機能する」ための3システムを追加。盤上の完全情報は維持。

1. **回線ルール**: 自CEOから味方の8近傍チェーンで繋がる駒だけオンライン。
   - オフライン駒: 走り駒(飛角・成含む)は1歩のみ・成り不可
   - 持ち駒の投入は自回線(オンライン集合)の8近傍の空きマス限定
   - 勝ち筋が「駒得」から「切断」に変わる。bot=配線、陣形=トポロジー
2. **ネットワーク機能による駒差別化**(動きは将棋のまま=学習コスト維持):
   - SAT(角)=同行・同列を無線中継 / HCK(銀)=隣接敵をタップしオフライン化(チェーン導通は維持)
   - F/W(金)=自身+隣接味方をタップから防護 / CEO=常時オンライン・タップ無効
3. **予告ブラックアウト**: 6手目から8手ごとにマスを予告(カウント4表示)→0でサーバーダウン(永久封鎖)。上の駒は消滅(CEOなら敗北)。最大5マス。決定論・完全公開(Into the Breach式)。持久戦を物理的に禁止し短時間を保証。

UI: 回線をSVGラインで常時可視化(SAT中継は破線)、OFFLINE/STUN表示、ダウンマス✕、予告カウント点滅。
v2の簡略化: 探索中はブラックアウト進行を静的近似(予告マス上の駒への評価ペナルティで回避誘導)、成り判定は移動前のオンライン状態を使用。

### v3 — 手応えの強化(1–2セッション)
- AI強化: 反復深化+静止探索+置換表で深さ4–5(マニア対応の要)。回線切断を狙う評価項の追加
- 不成の選択、打ち歩詰め判定 → 完全ルール準拠
- 強化プール拡張(12種目標): 例「トロイの木馬(敵陣に打った駒は1手見えない)」「ハニーポット(指定マスで敵駒停止)」「有線バックボーン(自陣2段は常時オンライン)」
- 敵AI思考ログ公開(評価値と狙い筋をターミナルに流す)、詰み表示、待った(FREEのみ)

### v4 — リテンション層
- デイリーリザルトの絵文字共有テキスト(Wordle型)、ローカルベスト/連続クリア記録
- 実績・アンロック(隠し強化、エンドレスモード: STAGE 4以降無限+敵強化スケーリング)
- 棋譜の再生・URL共有

### v5 — 拡張(需要があれば)
- ボス駒(原案の量子コンピュータ=2位置重ね合わせを「敵専用ボス」として復活 — 敵側限定なら完全情報性を壊さない)
- 7×7中間盤、GitHub Pages公開、モバイル最適化

### 原案要素の採否一覧
| 原案 | 採否 | 理由 |
|---|---|---|
| 持ち駒=ハック | ◎ 核に採用 | 構造的一致 |
| DDoS/バックアップ/ゼロデイ(カード) | ○ 強化ドラフトに変換 | 消費カード→パッシブ/チャージ化で管理コスト削減 |
| 衛星の端ワープ | ○ 強化として採用 | 唯一の動き改変。ローリスクで新鮮 |
| ハッカーのバックドア | △ v2以降 | 「操作可能」は実装重い。凍結系で代替中 |
| 量子重ね合わせ | △ v4敵ボス限定 | プレイヤー側だと完全情報が崩壊 |
| AP制/資源2種/レベル制/遅延帯域/セキュリティレベル/ダイス戦闘/勝利条件3種/クラウド・ダークウェブ拡張盤 | ✕ 不採用 | システム過多。短時間・完全情報と非互換 |
