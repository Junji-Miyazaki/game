# METEOR モダン化計画（参照: Falltopia / DESIGN_REF_falltopia.md）

目的: **ワイヤーフレーム基調を保ったまま**、Falltopia のモダン設計言語（ピクトグラフUI・
3択アップグレードカード・アイテムのシナジー・浮遊数値・密度＝報酬）を取り入れ、
「もう1周」を生む中毒性を実装する。ミサイルコマンド系の防衛ゲームに翻案。

## 現状（実装済み）
- ワイヤーフレーム岩ポリゴン隕石＋役割色（通常=赤/高速=明色/巨大/アイテム）。XORベタ塗り爆発。
- ステージ制＋タイプ（FAST/SWARM/TINY/GIANT/CHAOS）、ボス（上部HPバー）、ボス降下。
- 都市＝発射台（最初2→最大5）、手動/最寄り自動選択。散弾/ビッグ/ラピッド、都市別一時バフ。
- アイテム隕石（MULTI/POWER/WIDE/SCATTER/RAPID）、左側アクティブアイテムパネル。

## 採る（Falltopia 由来・優先順）
1. **3択アップグレードカード（中毒性の核）** — 各ステージクリア時に3枚から1枚選ぶ画面。
   - 角落としフレーム＋内側グロー、左に六角バッジ＋ピクトグラム、レアリティタグ、キーワード着色。
   - **ラン内永続**（そのプレイ中ずっと有効）。単体は小さく、**組み合わせで跳ねるシナジー**。
   - 例（防衛ゲーム翻案）:
     - 火力: 爆発ダメージ+1 / 爆発半径+20% / 迎撃速度+25%
     - 手数: 発射クールダウン-15% / 同時発射+1 / 都市発射台+1
     - シナジー: 「爆発で倒すと近くの隕石に連鎖(小爆発)」/「破壊した隕石が稀にコイン(スコア×)」/
       「巨大隕石撃破でスクリーン衝撃波」/「高速隕石を落とすと迎撃1発補充」
     - 生存: 都市に一度だけシールド / ボス被弾-1 / チャージ回復速度+
   - 引き直し(リフレッシュ)は将来検討（広告なし＝無料回数1などで）。
2. **ピクトグラフ圧縮HUD** — 上部を一列に整理。スコア/ウェーブ/都市数/ステージ名をアイコン化。
   ミニマルな細線パネル＋内側グロー。数字はモダンな等幅。プレイ画面を最大化。
3. **浮遊数値** — 隕石撃破時に対象色でスコア/コンボがポップして消える。コンボ計（連続撃破）。
4. **アイテム=遺物のシナジー** — 既存アイテムをカード体系に統合し、重ね掛けで効果が跳ねる。
5. **密度＝報酬** — ウェーブで空が隕石で満ちる実感（既存を強調、クリア演出を強化）。

## 採らない
- 広告リワード（買い切り/広告なし方針）。
- 放置(idle)自動戦闘そのもの（METEORはアクティブ防衛を維持）。

## 差別化（プレイヤー目線・ユーザー決定 2026-08-03）
ジャンル最大の不満＝「3択RNGのビルド事故」＋「救済（リロール等）が広告/課金ゲート」
（出典: Vampire Survivors コミュニティ議論、Survivor.io 系レビュー）。METEOR は能動スキルゲーである
ことを活かし、以下の**両方**を採用:
1. **腕前で稼ぐ選択権** — リロール/バニッシュ（不要カードを以後の抽選から除外）を広告でなく
   プレイの腕前で獲得: コンボ10到達ごとに REROLL+1、都市ノーダメでステージクリアすると BANISH+1。
   カード画面に小さく「REROLL x n / BANISH x n」ボタン。
2. **背水オーバードライブ** — 残り1都市になると発射CT半減＋スコア×2の OVERDRIVE モード
   （画面縁の脈動＋表示）。負け際を見せ場に変える逆転設計。

## フェーズ計画（分担）
- **P1（Fable）**: 3択アップグレードカード基盤＝ステージクリア割り込みUI＋`run` 永続アップグレード
  状態＋効果適用フック（火力/手数/シナジーの土台）。meteor.js に実装。← まずここ。
- **P2（Sonnet）**: ピクトグラフHUD（アイコン化・一列圧縮）＋浮遊数値/コンボ表示。
- **P3（Fable/Opus）**: シナジー系アップグレード拡充（連鎖/衝撃波/補充/コイン）＋バランス。
- **P4（Opus検証）**: 各フェーズの第三者チェック（`node --check`＋コードレビュー、可能なら実機/プレビュー）。

## 検証の制約（本セッション）
- プレビューMCPが切断中のため**ライブ目視は不可**。`node --check`＋コードレビュー＋Opus検証で担保し、
  見た目の最終確認は次回プレビュー/実機で行う（本ファイルに検証状況を追記していく）。
