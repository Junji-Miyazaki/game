## 2026-11-07 試作 v1：地球儀の地図と3都市（大阪・ロンドン・ニューヨーク）
- 依頼
  - 文明へのアンチテーゼをテーマに、世界の都市の象徴的な建物を崩して回るゲームにする。
  - LANDER の太陽系のような地図で、クリアした都市を回れるようにする。
  - LIGHTHOUSE は残し、別のゲームとして v1 から作る。
  - 題名は Birds を使う。「Birds Reclaim」と「Reclaim of Birds」のうち、英語として自然な BIRDS RECLAIM を推して採用した。
- やったこと
  - 新しいフォルダ `birds-reclaim/` を作った。
    - `00_log`、`01_docs`、`07_lab/proto_v1` を置いた。
    - 開発用サーバ `server.js`（:4179）を置き、`.claude/launch.json` に `birds-reclaim` を足した。
  - 試作を3つのファイルに分けた。
    - `stages.js`：材質、道中の建物、ボスの図面、鳥、都市。
    - `globe.js`：地球儀の地図。
    - `game.js`：遊びの本体。LIGHTHOUSE v9 の群れ・崩落・包囲を引き継いだ。
  - 地球儀について：
    - 陸地は手で置いた粗い海岸線を 2.5 度おきの点にした（陸の点は 1916 個）。正確な地図ではない。
    - 外部の地図データは取り込んでいない。
  - ボスは9つ（PLAN §3）。仕掛けを3つ入れた：ファンの風、金のガラスのまぶしさ、反射光。
  - 自然への回帰として、跡地の木、苔の色、クリア時に空と地面が緑になる演出を入れた。
- 直したこと（自動プレイで見つけたもの）
  - ボスの外壁が普通の建物と同じ硬さだった。そのため包囲の前に崩れ、どの都市も 1 秒ほどで終わっていた。外壁の強度（`shell`）をボスごとに持たせた。
  - 象徴の核を硬くすると、ロンドンとニューヨークは勝てなくなった。調べると、自由の女神は腕が折れて松明ごと落ち、着地で核が消えていた。
    - 落ちた核を地面に残す形に変えた。
    - ところが最後の 1 マスが台座の隙間に埋もれ、届かなくなった。落ちた列のいちばん上に載せる形に直した。
  - バタシーは核が建物の奥にあり、届かずに負け続けた。核を屋根の上へ移した。
  - 地図の題名が音のボタンと重なっていた。都市カードの行がボタンと重なっていた。どちらも配置を直した。
  - クリア後に崩れ落ちる塊にも点が入り、最高得点と表示がずれていた。クリア後は点を入れないようにした。
- 確かめたこと
  - 自動プレイ（`node 07_lab/proto_v1/sim.js auto 4`）：
    | 都市 | 勝ち | クリアまで |
    |---|---|---|
    | 大阪 | 3/4 | 115〜122 秒 |
    | ロンドン | 4/4 | 117〜139 秒 |
    | ニューヨーク | 4/4 | 106〜117 秒 |
    - 中ボスの包囲は 4〜15 秒。象徴は、核を消すまで 7〜19 秒、そこから崩しきるまで 3〜14 秒。
  - 強化なし（`none`）：3都市とも最初の中ボスの前後（24〜36 秒）で群れが尽きる。
  - ブラウザ（375×812）で確かめた：
    - 地図 → 飛び立つ → 包囲 → クリアの演出 → 結果 → 地球へ戻る → 緑が広がって次の都市へ回る、まで通った。
    - 9つのボスの見た目、ロンドンの雨、反射光の狙いの輪も見た。
    - コンソールにエラーはなく、横スクロールも出ない。
  - 確かめたあと、ブラウザに残った進み具合の保存は消した。
- まだ確かめていないこと

  - 地球儀のドラッグの感触。
  - 金の塔のまぶしさを、タップで避けられるか（自動プレイはタップしない）。

## 2026-11-09 試作 v3：鳥の種類を呼ぶ、仕掛けの鍵、映画風の冒頭と終わり（リーダー Opus 5.5）
- きっかけ：遊んだ3人の感想（2026-11-09）
  - 「攻撃を上げて、ボス前に仲間を増やせばどこでも勝てる。キャラの特性がないと飽きる」
  - 「鳥のデザインが波線だけ」
  - 「建物がもう少し視覚的に伝われば」
  - 話し合いのうえ、ユーザーが「一連の試作を進めて」と指示。
- 置き場所
  - `07_lab/proto_v3/` と `v3.html`。公開中の v2（`index.html`）は触っていない。
  - 保存は `birdsreclaim.v3` で、v2 の進み具合とは別。
- 変えたこと
  1. **強化のボタンをやめ、鳥を呼ぶ3つのボタンにした**
     - 出発前に、連れていく3種を地図のカードで選ぶ（枠をタップで入れ替え）。
     - 呼ぶたびに値段が 1.25 倍になる。
     - 威力と体力は v2 の強化分を初めから持つ（威力 5、体力 6）。中ボスを崩すたびに群れの勢いが上がる（威力 +1.6、体力 +2）。
     - 「守り」のボタンは無くなった。
  2. **鳥6種と役割**
     | 鳥 | 役割 | 効き目 |
     |---|---|---|
     | ムクドリ | 数で押す | 8羽ずつ、安い |
     | カラス | 硬い壁を割る | 外壁 ×2.5 |
     | ツバメ | 風に流されない | 冷却ファン、帆の横風、牛歩が効かない |
     | フクロウ | 光で目がくらまない | 光る建物、都庁の映像、スフィアの目玉が効かない |
     | ハヤブサ | 核へ一直線 | 核 ×4 |
     | ペリカン | 石を落として砕く | まわりのマスも壊す |
     - 最初はムクドリ・カラス・ツバメ。都市をはじめて還すたびに、フクロウ → ハヤブサ → ペリカンの順で仲間になる。
  3. **仕掛けを鍵にした**
     - 建物のカードに「効く鳥」を出す。連れてきていなければ、そう出す。
     - スフィアの目玉を強くした（開く 3.2 秒、範囲 210、固まった鳥は 1 秒動けない）。フクロウなしでは崩しにくい。
  4. **鳥の描き分け**：種類ごとに、羽の長さと幅、尾の形（燕尾・扇・細い）、頭、くちばし、目を変えた。
  5. **クリアごとのごほうび**
     - 鳥の言葉 1 行（13 行で詩になる）を、パスポートに記す。
     - 新しい鳥。
  6. **還った時の結果**：得点を少し見せてから、数字が崩れ落ちる。「還った土地 ◯ ha」「戻った鳥 ◯ 羽」に置き換わる（1マス＝5m 四方）。
  7. **映画風の冒頭（film.js）**
     - 4:3 の窓に、白黒の字幕カードを日本語・英語・フランス語で出す。ちらつき、粒子、縦の傷、四隅の暗さ、映写機の音を付けた。
     - 流れ
       1. フィルムの頭（タップで上映 → 3・2・1）
       2. 6600万年
       3. 羽を持つ恐竜
       4. 30万年
       5. 塔の 100 年（この1枚だけフランス語が大きい）
       6. 群れが文字をついばんで崩す
       7. 原色の題字を切り替える
       8. アイリスで色の付いた地球儀へ
     - 初回だけ流れる。地図のフィルムのボタンでもう一度見られる。
  8. **章のカード**：都市に入る時、白黒で「CHAPITRE 6 — BERLIN — FRANKFURT」を1秒出す。
  9. **終わりの映画**：13都市を還すと流れる。鳥の言葉 13 行が下から流れ、「勝ったとは思っていない」「夜が暗くなり、空が静かになった」と続き、FIN で閉じる。
- 確かめたこと
  - 自動プレイの方針を2つにした。
    - smart：効く鳥を1種＋カラス＋ムクドリを連れていき、場面ごとに効く鳥を呼ぶ。
    - naive：最初の3種のままで、ムクドリだけを連打する。

## 2026-11-09 試作 v3 その2：いまの本物の空、時間帯、待ち時間、得意・苦手、羽で育てる（リーダー Opus 5.5）
- ユーザーとの話し合いで決めたこと
  - 合う鳥がいなくても、ギリギリ崩せる。
  - 合う鳥を無限に増やせない。
  - 強化は鳥ごとに行い、持ち越す。
  - 攻撃の速さを入れる。
  - 苦手な鳥を入れる。
  - 説明は必要な場面で出す。
  - 天気はいまの本物の空。効き目は小さく、不利と有利を組にする。
  - 砂嵐というより竜巻は、一時的な演出。
  - 朝・昼・夕方・夜も現地から。
  - 強化した鳥の見た目を変える。
- 足したもの
  1. **いまの本物の空（sky.js）**
     - 都市を選んだ時と飛び立つ時に、Open-Meteo に都市の緯度経度だけを問い合わせる（鍵なし、15 分は覚えておく）。
     - 地図の都市カード、到着のカード、HUD に「いま　午後7:56　夜　快晴　16℃」と風を出す。
     - つながらない時は、月ごとの気候の表で決めた「季節の空」にする。気温は出さない。
  2. **時間帯**
     - 現地の時刻で、朝（5〜8時）・昼・夕方（16〜18時）・夜に分け、空の色を変える。
     - 本物の空が昼か夜かを返したら、それに合わせる。夜は星を出す。
  3. **天気の効き目（小さく、組にする）**
     | 天気 | 効き目 |
     |---|---|
     | 雨 | 鳥の速さ 0.9 倍、光の仕掛けの範囲 0.8 倍 |
     | 雪 | 速さ 0.9 倍、進みが遅い |
     | 霧 | 光の仕掛け 0.7 倍、進みが遅い |
     | 夜 | 光の仕掛け 1.1 倍 |
     | 強風（30km/h 以上） | 進みが遅い |
     - 到着のカードに効き目を書く。
  4. **竜巻**
     - 1都市に1度ほど、包囲の外で画面を横切る。砂漠の都市は砂の竜巻。
     - 横切る間は進みが少し遅くなるだけで、鳥と建物には触れない。
     - 雷雨の時は稲光が出る（見た目だけ）。
  5. **ボタンの待ち時間**：ムクドリ 1.2 秒、カラス・ツバメ 2.5 秒、フクロウ 3 秒、ハヤブサ 3.5 秒、ペリカン 4 秒。同じ鳥を呼ぶほど 1.25 倍ずつ高くなる。
  6. **速さ**
     - 鳥ごとに、突っ込む間隔と速さが違う（ツバメ 1.4、ハヤブサ 1.3、ペリカン 0.75 など）。
     - ボタンに威力を出す。
     - 建物のカードに「壁の硬さ」と「連れてきた鳥が何回で割れるか（一撃／◯回）」を出す。
  7. **建物の札と得意・苦手**
     - ボスの性質から札を自動で付ける：光・風・硬い（外壁 28 以上）・高い（55 段以上）・広い（48 マス以上で低い）。
     - 得意なら威力 ×1.35、苦手なら ×0.65。
     | 鳥 | 得意 | 苦手 |
     |---|---|---|
     | ムクドリ | なし | なし（基本の鳥） |
     | カラス | 硬い | 風 |
     | ツバメ | 風 | 光 |
     | フクロウ | 光 | 高い |
     | ハヤブサ | 高い | 広い |
     | ペリカン | 広い | 高い |
     - ペリカンは石で壁も割れるようにした（外壁 ×2、1回で 3 羽）。
  8. **羽と鳥の図鑑**
     - 都市を還すと羽がもらえる（はじめて 3 枚、2 回目から 1 枚）。
     - 地図の鳥のボタンから図鑑を開き、鳥ごとに威力と速さを 3 段まで上げる。段は持ち越す。振り直しは無料（試作の間）。
     - 育てた鳥は、威力の段で色の縁が光り、速さの段で急降下の軌跡が出る。
  9. **出発前のヒント**
     - 地図の都市カードに、都市の札と、連れていく枠の鳥ごとの ○・× を出す。
