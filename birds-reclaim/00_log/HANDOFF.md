## 2. 作業手順
- ローカル確認：`.claude/launch.json` の `birds-reclaim`（`node birds-reclaim/server.js`、:4179）。
- 自動プレイ：`node 07_lab/proto_v2/sim.js auto 4 [都市の番号|all]`（強化し続ける）／`none`（強化なし）。
  - 最初に「図面の点検」をする。置いただけで崩れるボス・名所・街並みがあれば名前を出す。新しい図面を足したら必ず ok を確かめる。
  - 地図・渡り・パスポートの描画も呼んでエラーを見る。
- JS を変えたら、`index.html` の `?v=` を次の値に更新する。
  `cat 07_lab/proto_v2/{stages,globe,game}.js | shasum | cut -c1-10`
- 都市を足すとき（`stages.js`）：
  1. `STAGES` に1件足す。国をまたぐなら区間に `c`（国）、地図の通り道に `via`、`HELLO` にその国のあいさつ。
  2. ボスを `BOSS` に足す。`make` で図面を描き、`shell` と `core` を決める。カードの `place` `year` `fact` `say` `after` `sub` も書く。年や数値は確かめてから。
  3. 名所を `LM` に足し、都市の `lm` に位置を書く。ボスと重ならない位置にする。
  4. 街並みの型が要るなら `GEN` に足す。
  5. sim で図面の点検と勝ち負けを見る（自動プレイで 4 回中 3 回以上勝つくらい）。
  - 核は外気に面した所（頂、屋根の上、建物の外に出た部分）に置く。横から見る 2D なので、穴や扉の中に置くと四方を囲まれて鳥が届かない（第2弾で5件あった）。
  - 地図の位置は `lat` と `lon` で決まる。
